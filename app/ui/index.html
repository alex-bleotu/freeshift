      Output to MyWhoosh

      Output mode

      MyWhoosh finds FreeShift on your local network as an OpenBikeControl controller. Pick "FreeShift" in MyWhoosh's controller pairing screen. If Windows asks about network access, allow it on private networks.

      FreeShift brings the MyWhoosh window to the front and presses the key set for each action. MyWhoosh shifts with I and K; if gears move the wrong way, use Swap shift up / down.

      ActionKey

      Keys: a letter or digit, Up, Down, Left, Right, Enter, Escape, Space, Tab, PageUp, PageDown, Home, End or F1 to F12. Leave empty to send nothing.

      Other Bluetooth buttons

      For a device that only reports "a button was pressed": one tap and a double tap become the Tap and Double tap buttons above. Find the characteristic with freeshift-cli explore. SRAM AXS needs more than this; see the README.
